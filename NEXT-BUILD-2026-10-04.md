## Deployment
Replace the repository working folder contents with this build (do not upload node_modules), run `npm install`, then `npm run build`, commit and push through GitHub Desktop. GitHub Actions deploys the built site.

## Important
Pricing, availability, booking, payment and medical outcomes are never automatically confirmed by the website. Human confirmation is required.
